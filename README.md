# PersonalOS

Sistema operativo personal minimalista.

## Stack
Django + DRF, PostgreSQL, React + TypeScript + Vite, Docker Compose.

## Estado
MVP en construcción: autenticación por código de activación, Hoy, tareas, notas y hábitos. Los módulos de nutrición, deporte y asistente IA se desarrollarán posteriormente.

## Seguridad
Nunca subir credenciales ni archivos `.env`. Consulta `env.example` y `DEPLOY.md` para instrucciones.
